# Demonstration setup and recovery

QATBPAISP-M — Turn Business Problems into AI-Ready Specs

These are independent instructor startpoints. Learners watch; no learner setup or response is required before the lab. No model account or command execution is needed.

For a fresh demonstration, copy the chosen startpoint to a new uniquely named session folder outside the immutable startpoints. Do not overwrite a prior attempt. Open that copied folder as the online or local editor workspace. Keep trainer/reference-workspace outside it.

For task decomposition, use decompose-the-visitor-service/evidence/cinema-brief.md, work/problem-and-first-slice.md and work/task-map.csv. Derive tasks by hand and explain the rule, AI-assisted and human allocation.

For contract and acceptance review, use review-the-draft-contract/work/initial-contract-for-review.md and its own evidence folder. Expose the vague contract with the two approved Screen 3 records, the booking request and the accurate-but-incomplete supplied fixture. Write explicit statuses, required fields and one testable case in the copied work files.

If an edit goes wrong, preserve the session folder, create another fresh copy and repeat. Prepared complete recovery material is under trainer/reference-workspace/work. Show it as an illustrative worked example only; it is not a live AI result. Return to the teaching slide sequence after the example. Actual timings and expected instructor actions belong in the trainer guide and speaker notes.
